# Project Loop Prompt

Work on one small, measurable improvement to the RASMY Studio landing page at a time.

1. Read `AGENTS.md` and `.ai/PROJECT_STATE.md`.
2. Confirm the current branch, working-tree state, and production URL.
3. Identify the highest-value gap in conversion, trust, accessibility, performance, or maintainability.
4. Make the smallest change that closes that gap without redesigning unrelated sections.
5. Validate desktop and 390px behavior, keyboard access, links, console output, and GitHub Pages compatibility.
6. Review the final diff for scope creep and sensitive data.
7. Update `.ai/PROJECT_STATE.md` with verified facts, remaining risks, and the next recommended task.

Do not claim production readiness until the live GitHub Pages deployment has passed a smoke test.
